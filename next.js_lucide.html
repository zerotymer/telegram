# Next.js + Tailwind CSS + Lucide-React 최적화 전략 Next.js App Router 환경에서 MUI(Material UI)와 같은 무거운 라이브러리 대신, **Tailwind CSS**와 **Lucide-React** 아이콘을 사용하는 것이 서버 컴포넌트(Server Components) 활용도를 높이고 성능을 최적화하는 데 유리합니다. ## 1. 핵심 설계 원칙 - **Zero-MUI**: `client-side` 런타임 오버헤드를 줄이기 위해 모든 스타일은 Tailwind CSS로 처리합니다. - **Server-First**: 복잡한 상태 관리가 필요 없는 레이아웃과 정적 요소는 서버 컴포넌트로 구성합니다. - **Lucide Icons**: `lucide-react`를 사용하여 가볍고 확장성 있는 아이콘 시스템을 구축합니다. ## 2. 권장 기술 스택 - **Framework**: Next.js 14+ (App Router) - **Styling**: Tailwind CSS - **Icons**: `lucide-react` - **Headless UI (Optional)**: 상태가 필요한 컴포넌트(모달, 드롭다운 등)는 `Radix UI`나 `Headless UI`를 사용하여 클라이언트 컴포넌트 범위를 최소화합니다. ## 3.
